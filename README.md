# نظام كاشير محل البلاستيكات - React

نظام متكامل لإدارة محل البلاستيكات مبني بتقنية React مع واجهة مستخدم حديثة ومتجاوبة.

## المميزات

### 🛒 نقطة البيع (POS)
- إضافة المنتجات للسلة بسهولة
- البحث السريع بالباركود أو اسم المنتج
- دعم نوعين من العملاء (قطاعي وجملة)
- حساب تلقائي للضريبة (15%)
- طباعة الفواتير
- إدارة المخزون تلقائياً

### 📦 إدارة المخزون
- إضافة منتجات جديدة
- تعديل وحذف المنتجات
- عرض حالة المخزون (جيد، متوسط، منخفض، نفذ)
- تصدير تقرير المخزون

### 📊 التقارير والإحصائيات
- إحصائيات المبيعات اليومية
- تقارير مفصلة للمبيعات
- فلترة البيانات حسب التاريخ ونوع العميل
- تصدير التقارير بصيغة Excel
- طباعة التقارير

### 🔐 نظام الأمان
- تسجيل دخول آمن
- حفظ البيانات محلياً
- واجهة مستخدم متجاوبة

## التثبيت والتشغيل

### المتطلبات
- Node.js (الإصدار 14 أو أحدث)
- npm أو yarn

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone https://github.com/yourusername/cashier-system.git
cd cashier-system
```

2. **تثبيت التبعيات**
```bash
npm install
```

3. **تشغيل المشروع محلياً**
```bash
npm start
```

سيتم فتح التطبيق تلقائياً على `http://localhost:3000`

### بناء المشروع للإنتاج
```bash
npm run build
```

## النشر على GitHub Pages

### 1. إعداد GitHub Pages

1. اذهب إلى إعدادات المستودع على GitHub
2. انتقل إلى قسم "Pages"
3. اختر "Deploy from a branch"
4. اختر فرع `gh-pages` أو `main`
5. احفظ الإعدادات

### 2. تحديث package.json

تأكد من تحديث `homepage` في ملف `package.json`:

```json
{
  "homepage": "https://yourusername.github.io/cashier-system",
  ...
}
```

### 3. نشر المشروع

```bash
npm run deploy
```

أو يدوياً:

```bash
npm run build
git add build
git commit -m "Build for deployment"
git push origin main
```

## هيكل المشروع

```
src/
├── components/
│   ├── Login.js          # صفحة تسجيل الدخول
│   ├── Dashboard.js      # لوحة التحكم الرئيسية
│   ├── POS.js           # نقطة البيع
│   ├── Inventory.js     # إدارة المخزون
│   ├── Reports.js       # التقارير
│   └── *.css            # ملفات الأنماط
├── hooks/
│   └── useData.js       # Hook لإدارة البيانات
├── App.js               # المكون الرئيسي
└── index.js             # نقطة الدخول
```
